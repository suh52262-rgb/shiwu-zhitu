# 视物知途 1.4.0-local-demo.20261015

Windows x64 / Python 3.11本地演示候选版。五个工作区已集成；不是公网正式服务，也不承诺Linux/macOS已验证。建议16GB内存、至少10GB可用空间。版本、依赖、数据与来源哈希见VERSION.json、DATA_INVENTORY.json、manifest.json。

## 从GitHub获取源码

源码与完整本地数据包是两种交付。GitHub源码不包含教材正文/图片/向量、BGE模型、密钥、真实视频、学生历史或离线wheel。代码仓库下载后可以安装requirements.txt并运行导览；完整教学需自行准备合法教材、BGE与数据库，或获取经授权的本地数据包。公开发布前还须核查题库及配图、教材派生材料、模型和依赖许可，不把本地交付包直接当GitHub公开附件。此次未推送或发布远端。

## 完整本地包：安装与恢复

解压到新目录，不覆盖旧工作区。准备Python3.11、Docker Desktop Linux容器。首次拉取Docker镜像需网络；包内Windows wheel可离线安装。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File deployment/Setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File deployment/Preflight.ps1 -Services
powershell -NoProfile -ExecutionPolicy Bypass -File deployment/Restore.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File deployment/Accept.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File deployment/Start.ps1
```

默认入口8500，学生8501、教师8502、题库8503、教材8504；后端8000。Start默认五页；`-StudentOnly`只启动学生页。并行演示可用`-BackendPort 28000 -FrontendPort 28501`，五页为28500–28504，页内链接随之调整。端口冲突拒绝启动，不接管他人服务。

Setup为当前版本生成独立Compose项目；可用`-PostgresPort 25432 -QdrantPort 26333`，仅首次生成.env时替换端口，已有.env不覆盖。检查配置与项目名后再运行。Restore只接受空库和不存在的向量集合；失败保留现场，使用新空实例恢复，不反复覆盖半恢复数据库。

## 联网、模型费用与无密钥体验

密钥只填写本地.env；不发到聊天、GitHub或日志。默认demo使用deepseek-flash、诊断v5、提示v5、复盘v4。`Preflight.ps1 -Online`只检查密钥是否配置，不调用模型、不证明余额或权限。API401/402/400分别核对密钥、余额、模型支持；不靠重新上传解决。

无密钥可以浏览导览、已导入题目和教材、空教师页；不能生成新提示/OCR/复盘/Graph。包不含私人历史，所以不能保证能浏览真实学生的旧案例。可阅读发布说明中原验收记录，但不能把静态材料当本机实时模型输出。

## 验收与故障

免费Accept验证包哈希、PG/Qdrant数据计数及抽样、BGE、实际检索和API；检索检查关闭付费重排/扩展，只验证基础功能，不证明RAG语义充分性。执行前学生历史须为空。Preflight的TCP可达不等于恢复成功；health只证明应用进程可响应。

手动联网验收：照片识别与分级求助、OCR更正、文字续答、完成后新开；视频上传、进度、刷新找回、按需复盘及修订；教师证据核对；自定义题目草稿、修订发布、Graph生成与独立复核。此过程产生模型费用，实际本轮完成范围见deployment/验收记录.md，未完成的不能写为通过。

`deployment/TestOffline.ps1`运行离线选集，不扩大skip；历史v22仅覆盖冻结文字案例。本包当前业务变化不获历史质量自动背书。

停止应用执行deployment/Stop.ps1；停止数据执行`docker compose stop`，保留卷。不要使用down -v清空数据。移动目录后更新.env的模型路径。数据备份恢复和清理见[数据维护说明](数据备份恢复与清理.md)。
