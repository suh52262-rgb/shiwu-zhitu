# 首次使用与日常操作

双击根目录的 **首次使用.cmd**。它是本机操作菜单，不连接模型、不自动安装或删除数据；只有选择对应操作才执行。

| 需要做什么 | 菜单 | 说明 |
|---|---|---|
| 了解准备条件 | 1 使用说明 | Windows x64、Python3.11；完整教学还需Docker数据服务、数据及模型 |
| 看缺什么 | 2 环境检查 | 只读检查，不打印密钥；命令存在不等于服务可用 |
| 首次安装 | 3 安装/初始化 | 完整包安装锁定wheel并启动隔离服务；源码安装依赖，数据/模型需另准备 |
| 首次恢复教材 | 4 首次恢复教材 | 仅完整包、新空实例；须输入RESTORE；不恢复学生历史 |
| 验证恢复 | 5 免费验收 | 只对完整包；会加载BGE，不调用付费重排或教学模型；应在试用前执行 |
| 日常启动 | 6 启动工作区 | 完整包启动后端及五页；源码先按指南启动后端，再启动页面 |
| 排查错误 | 7 查看日志目录 | 打开本机data/logs，不上传日志；分享前脱敏 |
| 结束展示 | 8 停止所属应用 | 保留数据库卷；源码的独立后端需在原终端停止 |
| 不配置数据先看看 | 9 只看导览 | 只开导览，链接不会自动启动其他页；Ctrl+C停止 |

已有数据的日常演示只需启动，不要重复执行恢复。完整包默认导览8500、学生8501、教师8502、题库8503、教材8504，后端8000。

想看在线辅导：在本地.env配置自己的密钥。环境检查只证明“填写过”，不能证明余额或生成服务可用。网络模型故障时保留任务号和错误，不反复上传；照片超时后后台仍可能运行，先检查记录。本轮DeepSeek服务故障期间，不把页面能打开写成在线辅导通过。

菜单也可在终端使用：`powershell -NoProfile -ExecutionPolicy Bypass -File deployment/FirstUse.ps1 -Action check -NoPause`。加`-Json`可只输出前置检查摘要。`-Action logs -NoOpen -NoPause`仅打印目录、不打开窗口。自定义完整包应用端口可传`-BackendPort 28000 -FrontendPort 28501`，但数据库端口须先按Setup说明配置。

源码详细步骤见[GitHub源码快速开始](GitHub源码快速开始.md)，完整包见[快速部署](快速部署.md)，数据维护见[备份恢复与清理](数据备份恢复与清理.md)。本菜单不提供删除卷、清理作答或公开发布操作。
